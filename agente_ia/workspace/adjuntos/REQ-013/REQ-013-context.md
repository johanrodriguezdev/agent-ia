# Contexto REQ-013 — Rediseño UI escritorio NODDOO estilo chat de IA

## Resumen ejecutivo
Rediseñar el panel de control de escritorio de NODDOO (PyQt6) para migrar del layout actual
(sidebar navegación + indicador circular central + panel derecho de widgets de estado) hacia
un layout tipo chat de IA moderno (ChatGPT/DeepSeek/Claude): conversación centrada, sidebar de
historial/navegación, burbujas de mensajes, composer de texto inferior. Es preparación para
empaquetar la app como instalable de escritorio local.
